# Conformance and compatibility

The core repository owns the executable conformance matrix, fixture schema, and
compatibility policy. Read the authoritative:

- [conformance matrix](https://github.com/StellarReplay/stellar-replay/blob/main/docs/CONFORMANCE_MATRIX.md)
- [compatibility and deprecation policy](https://github.com/StellarReplay/stellar-replay/blob/main/docs/COMPATIBILITY.md)
- [fixture provenance guidance](https://github.com/StellarReplay/stellar-replay/blob/main/docs/FIXTURE_PROVENANCE.md)

This repository provides extended explanations and integration guides. It does
not redefine supported methods, pagination behavior, schema versions, or replay
semantics.
